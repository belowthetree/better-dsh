# @deepseek-ai/dsh-experimental-client-ui-voice-input

[English](README.md) | 中文

## 概述

此可选浏览器插件在模型选择器与发送按钮之间添加空心麦克风图标。识别就绪后，点击展开录音栏，显示实际音量以及取消、停止按钮。声波高度低于录音按钮高度。停止后转写到草稿。录音、麦克风选择与转写属于 [client-voice-capture](../client-voice-capture/README.zh.md) 中的共享采集服务；本包只是它的一个消费者。识别偏好和模型准备放在插件设置中；语言选项来自所选 Provider。其中的免手动设置会把转写作为普通消息提交，而不是留在草稿中。

## 使用此包

在插件管理页启用[语音输入 Bundle](../voice-input-bundle/README.zh.md)。插件注入 `voiceCapture`，因此组合中还必须挂载 [client-voice-capture](../client-voice-capture/README.zh.md)；该包负责挂载语音 Remote 并拥有录音器。缓存检查后，缺少模型时弹出安装引导，可选择“前往安装”或“稍后”。“前往安装”打开 Bundle 详情，再点击“下载并准备”才开始安装。缓存完整时不弹引导，也无需重复安装。识别未就绪时不显示麦克风悬停提示，点击后才打开同一个引导弹窗；点击引导按钮进入语音 Bundle 详情，不会录音或下载。缓存检查、正在准备、准备失败或服务断连时，弹窗改为引导查看状态、进度或错误详情。弹窗将焦点移到导航按钮，并将 Tab 切换约束在弹窗内；选择“稍后”或按 Escape 关闭时恢复此前焦点，不改变或提交草稿。准备前，本地 Provider 可展示磁盘、内存与安装时间的估算。准备摘要默认折叠；展开后可查看已完成、当前和未开始的步骤。就绪后点击麦克风，允许访问，再点击停止以转写。取消或 Escape 丢弃录音。录音属于共享服务，因此工具栏卸载、窗口失焦或页面隐藏时采集继续；回到会话即可再次看到进行中的录音。识别反馈留在工具栏内部。Provider 和语言偏好在 Bundle 详情中通过 Settings 服务保存。浏览器麦克风访问需要 HTTPS 或环回地址，以及操作系统权限。

在 Bundle 详情中使用原生**输入设备**选择器，跟随系统默认设备或选择浏览器可用的麦克风。系统默认在名称可用时显示当前设备名。Bundle 详情处于活动状态时，已选输入的实时电平持续显示在字段右侧；切换设备会为该设备重新启动预览。隐藏或离开页面、禁用插件时会释放预览，包括随后才批准的麦克风授权。浏览器会记住设备选择并用于后续录音，与 Host 的识别设置分别保存。插入和拔出设备会刷新选项，不打断仍然可用的已选输入。已选设备断开后会作为禁用选项保留名称和位置，并显示“不可用”。页面处于活动状态时，重新连接会恢复预览；改选其他输入后移除不可用选项。录音中断后需要手动重新开始。权限被拒绝时仍可选择其他设备；明确指定的设备不会静默回退到其他输入。

下载或重试前，**模型下载源**提供自动选择及 Host 公布的源。SenseVoice 默认提供 Hugging Face 和 HF-Mirror；固定私有部署仅显示配置的源。手动选择只使用指定源，自动选择沿用提供方的比较与回退策略。当前卡片中的重试会保留选择，不修改部署配置或识别偏好。准备期间不能改源，资源就绪后隐藏源选择器。

`pluginNavigation` 为可选服务：没有它时插件照常启动，设置对话框只在该服务存在时提供详情按钮。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>维护者信息 — 点击展开</summary>

插件注册一个输入框贡献，以及 Bundle 的设置与准备贡献，再把共享服务适配为它们注入的属性。插件不拥有录音器：`begin`、`finish`、`cancel`、实时快照和麦克风预览都来自 [client-voice-capture](../client-voice-capture/README.zh.md)，该包同时负责挂载语音 Remote 贡献。服务发布同一份快照；工具栏据此推导请求、录音、转写与反馈阶段，并读取电平绘制声波，因此重新挂载的输入框会接回进行中的采集而不是丢弃它。

由于采集归服务所有，窗口失焦、页面隐藏和输入框卸载都不再停止录音；只有取消、Escape、设备中断或显式停止才会结束它。切换 Session 时采集继续，下一次转写改为投递到当前草稿而不是被丢弃。命令失败会让服务回到空闲，并以带标记的拒绝值到达；工具栏负责本地化。原编辑器选区仍携带草稿版本，草稿变化时转写文字保留在麦克风旁，供显式插入或丢弃。插件拥有的一份准备状态订阅服务于输入框、安装引导和详情。这些视图使用既有 Slot 生命周期，不拥有准备任务。面板收起时从悬浮球完成的采集会把转写暂存在共享服务中，本控件挂载后立即插入。

</details>

<a id="model-experience"></a>
## 模型体验

无，因为录音与准备不进入模型请求；之后的文字由普通用户提交拥有。

#### KV 缓存影响

没有直接影响；普通提交拥有消息内容。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 需要 [client-voice-capture](../client-voice-capture/README.zh.md) 行；缺少该行时插件保持未激活，麦克风控件不会出现。
- 不提供自动发送、常开麦克风、唤醒词、流式字幕或语音合成。“本地”指 Host 所在机器，可能与浏览器所在机器不同。
